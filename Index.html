Guide

Use the analyzer with clear assumptions

What it does

It turns deck facts and explicit assumptions into transparent mana and probability questions.

Using a deck

Choose a format, paste a list, and parse it. Resolved evidence is kept separate from unresolved cards.

Formats

Constructed uses four-copy rules, Singleton uses one copy, and Brawl uses 59 main-deck cards plus one commander.

Mana terms

A pip is a colored or colorless symbol in a cost. A source is a card or ability that can produce a relevant mana type under stated conditions.

Methods

Source counts estimate how many sources a deck contains. Exact probability measures a specified draw event. Simulation estimates repeated trials. They answer different questions.

Pay-2-life lands

The optional life analysis estimates access and expected payment under the selected play/draw, turn, and payment assumptions. It does not assume every land enters untapped.

Assumptions matter

Opening hand, draw behavior, play or draw, mulligans, and conditional effects can change a result. Read the assumptions beside every result.

Why results differ

Different MTG calculators may use different populations, draw horizons, source definitions, or models. Compare assumptions before comparing percentages.

Getting started

Choose any destination. Calculators work manually without a deck; a loaded deck can provide optional starting values.

Manual vs current deck

Manual values are yours to set. Current-deck values are derived where supported and remain editable assumptions rather than changes to the deck.
